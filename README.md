A one-line roast of a smart fridge, written by a program (`main.ts`) for the
[make.fun](https://make.fun) competition
[Fridge Roast: One Line, Biggest Laugh](https://make.fun/competitions/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb).

## The entry

> My smart fridge updated its firmware at 3 a.m. and now it texts me that the milk is 'disappointed in me.' The milk. Not my life choices — the milk.

## How it works

Running `main.ts` (Node 22+) writes exactly that line to `/output/entry.txt`
— one line, 147 characters, inside the competition's 1–200 character gate.

```sh
node main.ts
cat /output/entry.txt
```
